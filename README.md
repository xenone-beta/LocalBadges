# LocalBadges

**Локальные бейджи верификации для exteraGram и AyuGram**

Помечайте пользователей, ботов, каналы и группы любым значком: видите его только вы, на серверах Telegram ничего не меняется.

## Возможности

| | |
|---|---|
| **Четыре вида бейджа** | Major, Hold, галочка (verified) и кастомный эмодзи |
| **Для любых объектов** | Пользователи, боты, каналы и группы, с подписью «Пользователь верифицирован…» в профиле |
| **Временные бейджи** | Бессрочно, на 1, 7 или 30 дней; просроченные исчезают сами |
| **Быстрая выдача** | Из меню профиля и из меню чата, либо из менеджера в настройках плагина |
| **Менеджер** | Поиск, фильтры, постраничный список, предпросмотр и массовая выдача по списку ID |
| **История и откат** | Журнал последних действий с возможностью отменить любое |
| **Экспорт и импорт** | Резервная копия всех бейджей через буфер обмена в формате JSON |
| **Скрыть всё** | Один переключатель убирает все бейджи, не удаляя их |
| **Встроенные метки** | Официальные лица и каналы, пометка Scam для пользователей с жалобами |
| **Supporter** | Бейдж за поддержку проекта, который видят все пользователи плагина |
| **Автообновление** | Плагин сам проверяет новую версию раз в пару часов |

Настройки в стиле Material 3. Диалоги в профилях и чатах оставлены простыми, как в самом клиенте.

## Установка

1. Скачайте [`LocalBadges.plugin`](LocalBadges.plugin) из этого репозитория.
2. Откройте файл в exteraGram или AyuGram и подтвердите установку, либо отправьте его себе в «Избранное» и нажмите на вложение.
3. Включите плагин в разделе плагинов и перезапустите клиент, если он попросит.

Требуется exteraGram 12.1.1 или новее.

## Как пользоваться

**Выдать бейдж.** Откройте профиль человека, бота, канала или группы, нажмите на меню (три точки) и выберите **Local Badges**. То же самое есть в меню чата в списке диалогов. Выберите тип бейджа, при необходимости срок и подтвердите.

**Управлять всем сразу.** В настройках плагина откройте менеджер: там список всех выданных бейджей, поиск, фильтр по типу, массовая выдача, история действий и резервные копии.

**Снять бейдж.** В том же диалоге выберите «Удалить бейдж» или отмените действие в истории.

## Supporter

Supporter это знак поддержки проекта. Он **покупается один раз и навсегда за 50 ⭐** в боте [@BadgesPayBot](https://t.me/BadgesPayBot).

- **Подарок.** Можно подарить Supporter другому пользователю.
- **Промокоды.** Бот принимает промокоды на бессрочный или временный бейдж.
- **История.** Покупки, подарки и промокоды видны в боте командой `/history`.
- **Отображение.** Бейдж Supporter показывается у вас у всех, у кого стоит LocalBadges. В плагине есть страница со статусом, датой получения и кнопками для покупки, подарка и ввода промокода.

Список Supporter хранится в [`supporters.json`](supporters.json) и обновляется ботом автоматически. Плагин перечитывает его раз в час. Telegram ID покупателей публикуются в открытом виде: об этом бот сообщает до оплаты.

| Файл | Назначение |
|---|---|

## Конфиденциальность

Бейджи, выданные вами, хранятся только в настройках плагина на вашем устройстве. Плагин ничего не отправляет на сервер, кроме загрузки публичных файлов этого репозитория (список Supporter и проверка обновлений).
